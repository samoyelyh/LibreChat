# Phase 9：管理员创建用户账号

## 功能入口

系统管理员登录用户端后，打开“设置 → 账号 → 用户管理”，即可看到“创建用户账号”。普通用户不会显示这一功能。

## 已实现能力

- 管理员填写姓名、用户名、邮箱和初始密码创建公司账号。
- 创建时可选择一个业务角色和一个部门；部门对应 LibreChat Group。
- 新账号为本地邮箱登录账号，并直接标记为邮箱已验证，不依赖外部邮件服务。
- 公开注册和社交注册继续保持关闭。
- 表单不提供系统级 `ADMIN` 角色，避免通过日常账号创建流程误授超级管理员权限；小写业务角色 `admin` 可正常选择。
- 密码只在提交请求时发送，接口响应、审计信息和最近账号列表均不返回密码。
- 邮箱重复、角色或部门失效时返回明确错误；账号已创建但部门分配失败时自动删除该临时账号。

## 权限边界

创建接口为 `POST /api/admin/users`，依次校验登录状态、后台访问权限、用户管理权限、角色管理权限和部门管理权限。未登录或普通用户无法调用。需要增加系统级管理员时，仍使用受控的官方 CLI 和既有运维流程。

## 验收方法

1. 使用系统管理员账号登录 `http://192.168.0.27:7999`。
2. 打开“设置 → 账号 → 用户管理”。
3. 确认角色列表包含业务角色，且不包含大写系统角色 `ADMIN`。
4. 确认部门列表包含预置的六个部门。
5. 使用测试邮箱创建账号，退出管理员账号后验证新账号可以登录。
6. 再次使用相同邮箱创建，确认系统提示账号已存在。
7. 确认登录页仍无公开注册入口。

`deploy/verify-phase9.sh` 会检查容器健康、未登录调用被拒绝、公开注册关闭、前后端构建产物存在，并执行 Phase 8 回归验证；脚本不会创建测试用户。

## 回滚

按既有 `deploy/rollback.sh` 恢复上一组不可变镜像和配置。回滚不删除 MongoDB、上传文件或其他持久卷；本功能没有新增数据库集合或迁移。
